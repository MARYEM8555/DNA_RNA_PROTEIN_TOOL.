# DNA / mRNA / Protein Tool

A simple Python command-line tool for biological sequence processing:
- **Transcription:** Convert DNA to mRNA (supports coding and template strands).
- **Translation:** Translate mRNA into a protein sequence starting from the first `AUG` start codon.
- **Reverse Complement:** Compute the reverse complement of a DNA sequence.

## Usage

Run the interactive CLI:

```bash
python cli.py
